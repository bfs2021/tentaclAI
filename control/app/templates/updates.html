Updates

Claude Code is installed when the image is built – an update rebuilds the image and recreates the container.

What happens during an update?

  1. docker compose build --pull claude – fresh base image and the requested Claude Code version
  2. docker compose up -d --force-recreate claude – recreate the container
  3. remove old, unused images of the stack

Login, settings, SSH, services and projects are kept (they live on the host).
